# 日常の判断を扱う追加教材の調査と実装

調査日：2026-11-05。既存のメール・SNS投稿・写真・コメントの4教材に、情報の再共有、ネット通販、偽の感染警告を扱う3教材を追加した。

公的機関が注意を呼びかけている事例から、既存教材で扱っていない場面を選んだ。発生頻度の順位付けや、被害件数の統計的な比較は行っていない。「よくあるミス」を、学習者が操作して確かめられる判断の場面として構成している。

## 調査結果と体験への反映

| 教材                                 | 資料から確認した点                                                                                                                                                                                                                                                                        | 試せる操作                                                                                                                                                         |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| L05 そのシェア、いつの情報？         | 古い情報や、背景が省かれた情報を広める場合がある。発信元・日付・他の情報との照合が必要。[政府広報オンライン](https://www.gov-online.go.jp/article/202403/entry-5920.html)、[広報誌『ぼうさい』第109号](https://www.bousai.go.jp/kohou/kouhoubousai/r05/109/news_03.html)                  | 友人の投稿から転載元を開く、画像全体の日付を見る、主催者の最新案内と比べる。そのままシェアする、保留する、確認時刻と出どころを添えて伝える、投稿を訂正・削除する。 |
| L06 その激安ショップ、買って大丈夫？ | 極端な安さ、販売者情報、支払手段の制限などを複数の観点から確認する。商品ページと手続き中の支払条件が異なる場合がある。[警察庁](https://www.npa.go.jp/bureau/cyber/countermeasures/fake-shop.html)、[消費者庁](https://www.caa.go.jp/policies/policy/consumer_policy/caution/caution_033/) | 販売者・連絡先を見る、別の店と比べる、注文画面で条件の変化を確かめる。購入を見送る、架空の振込後に未着の状況を見る、取引記録をまとめて相談先を確認する。           |
| L07 突然の警告、電話して大丈夫？     | 偽の警告から電話や遠隔操作へ誘い、支払いを求める手口がある。ページ内の偽の閉じるボタンも使われる。[IPA](https://www.ipa.go.jp/security/anshin/attention/2024/mgdayori20241119.html)、[警察庁](https://www.npa.go.jp/bureau/cyber/countermeasures/support-fraud.html)                      | 表示元を調べる、警告内のボタンと模擬ブラウザのタブ操作を比べる。通話をやめる、遠隔操作やギフトコード共有を模擬する、接続を切り、進んだ段階に合う対処を確認する。   |

支払後の解説では、銀行振込による詐欺被害が疑われる場合の警察・振込先金融機関への相談と、返金が保証されない点を[金融庁の案内](https://www.fsa.go.jp/policy/kyuusai/furikome/index.html)で確認した。サポート詐欺では、支払記録の保存、カード会社や電子マネー管理会社への連絡、警察への相談を[警察庁の案内](https://www.npa.go.jp/bureau/cyber/countermeasures/support-fraud.html)に基づいて説明する。

既存教材の[フィッシング対策](https://www.npa.go.jp/bureau/cyber/countermeasures/phishing.html)と[インターネット上の誹謗中傷等への対応](https://www.npa.go.jp/bureau/cyber/countermeasures/defamation.html)も確認した。配送メールの偽装や投稿によるプライバシー侵害は既存の課題で扱っているため、今回の追加は別の判断に焦点を当てた。

既存の参考資料である[消費者教育ポータルの事例集紹介ページ](https://www.kportal.caa.go.jp/teaching-material/000914/)は、今回の直接取得で503になった。検索結果の紹介文は確認できたが、事例集PDFの内容を読めたものとして扱っていない。政府広報のページも直接取得は403だったため、検索結果で取得できた同ページの本文を確認した。追加教材の根拠は、本文を確認できた上記の個別資料を使用している。

## 教材としての構成

- **設定はすべて架空。** 投稿者、イベント、店、商品、日時、価格、URL、会話は教材用に作成した。実際の事件や統計の再現ではない。URLには `.example` を使い、実際の電話番号・口座番号・ギフトコードは表示しない。
- **一つの特徴だけで断定しない。** 安い商品、個人名義、名称の違い、発送の遅れだけで詐欺と決めつける説明は避けた。主催者の開催予定も、将来の開催を保証するものとはしていない。
- **進めた後の対処も試せる。** 訂正が全員に届くとは限らない、削除しても保存済み情報は残り得る、遠隔接続を切っても過去の操作や支払いは取り消せない、という違いを結果に反映した。
- **実操作は行わない。** 外部通信、購入、振込、通話、アプリ導入、遠隔操作は発生しない。警告音、実ブラウザの全画面化や終了妨害も使わない。模擬操作の表示を残し、共通の終了・リセット機能を利用できる。
- **既存の体験画面を維持。** 元の `MockApps.tsx`、`PhotoScene.tsx`、`experience.css` は変更していない。共通の模擬ブラウザ・SNSの部品を使い、新規画面のCSSを `everyday.css` に追加した。

L05の訂正・保留などの分岐は、調査した確認方法を練習できるように設計したもの。緊急時の救助や避難判断を扱う場面にはしていない。L07では、本物のOS・セキュリティソフトの警告まで無視する学習にならないよう、表示元の確認と正規の窓口への相談を解説している。
